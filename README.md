
# Workspace Connect

Projet de stage de BTS SIO. Réalisation d'une application web pour les reservations de places de parkings, salles de réunions, boxs et bureaux d'open space.



## Contexte

Le sujet de ce stage, devait être capable de développer une application web pour géré un système de réservations de ressources d'entreprise. Le tout assisté par l'IA (majoritairement Gemini 3 Flash)


## Roadmap

## Environment Variables

To run this project, you will need to add the following environment variables to your .env file

`DB_HOST`
`DB_PORT`
`DB_NAME`
`DB_USER`
`DB_PASS`


## Features

- Réserver sur plusieurs jours
- Géré ses réservations
- Invité des collègues
